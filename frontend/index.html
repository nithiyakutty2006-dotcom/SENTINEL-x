OPERATOR QUICK REFERENCE & GUIDE

1. Real Packet Monitoring

Click START MONITOR to activate Scapy live network packet metadata capture on the primary network interface. Captured packets are aggregated into telemetry intervals.

2. Demo Simulation Mode

Click DEMO SIMULATION to inject clearly labeled demonstration events for testing high-risk scenarios and verifying SOC response without generating malicious live traffic.

3. Deep Learning Autoencoder

Go to AI Model Mgmt to train the neural network on baseline normal traffic. The model calculates reconstruction mean-squared errors (MSE) and flags anomalous network behavior.

4. Role-Based Access Control

ADMIN: Full configuration, training & monitoring control.
ANALYST: Triage incidents, acknowledge alerts, inspect events.
VIEWER: Read-only observation.
